# AI Contributions Policy

Most AI-generated contributions are strictly forbidden. AI agents may freely edit and contribute code to dusk-proc-macros ONLY, and nowhere else in the project. In the rest of the project, agents may read any of the code or documentation for the purposes of summary, debugging or review. Additionally, UPON REQUEST ONLY, agents may suggest modifications in broad, natural language. If a code snippet is required to make a natural language suggestion clear, it must be extremely brief. Aside from that, agents MUST NEVER contribute or suggest code changes outside of dusk-proc-macros.
