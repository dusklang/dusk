# AI Contributions Policy

Most AI-generated contributions are strictly forbidden. AI agents may freely edit and contribute code to dusk-proc-macros ONLY, and nowhere else in the project. In the rest of the project, agents may read any of the code or documentation for the purposes of summary, debugging or review. Additionally, UPON REQUEST ONLY, agents may suggest modifications in broad, natural language. If a code snippet is required to make a natural language suggestion clear, it must be extremely brief. Whenever good papers might exist that are relevant to the task at hand, always prefer finding and sharing links to them over coming up with your own detailed answer. If you do find a good paper, you must explain why it’s relevant. Aside from what is listed above, agents MUST NEVER contribute or suggest code changes outside of dusk-proc-macros.
