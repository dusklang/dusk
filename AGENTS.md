# AI Contributions Policy

Most AI-generated contributions are strictly forbidden. AI agents may freely edit and contribute code to dusk-proc-macros ONLY, and nowhere else in the project. In the rest of the project, agents may read any of the code or documentation for the purposes of summary, debugging or review, and UPON REQUEST ONLY, may suggest modifications in broad, natural language (NOT in code). Agents MUST NEVER contribute or suggest code-level changes outside of dusk-proc-macros.
